TRENA — подключение реального Telegram-бота
============================================

На любом Windows-ПК:
1. Скопируйте всю папку TRENA (целиком).
2. Дважды щёлкните ЗАПУСК.bat — откроется браузер.
   Без токена работает демо (чат имитируется).

Чтобы слать реальные сообщения в Telegram:

1. Откройте Telegram → найдите @BotFather
2. Команда /newbot → задайте имя и username бота
3. Скопируйте токен вида: 7123456789:AAH...
4. Откройте файл server\config.json в Блокноте
5. Вставьте токен:
   {
     "botToken": "СЮДА_ТОКЕН",
     "port": 8765,
     "coachSecret": "trena-local"
   }
6. Сохраните файл и снова запустите ЗАПУСК.bat

Связка атлета с Telegram:
1. Атлет пишет боту /start — бот ответит chat_id
2. В TRENA → Профиль атлета → «Telegram» вставьте chat_id
   (или выберите из списка тех, кто уже написал боту)
3. «Отправить в Telegram» уйдёт в реальный чат
4. Кнопки под тренировкой (Выполнил / Частично / Пропустил)
   возвращают отчёт в кабинет тренера

Презентация без интернета:
- ЗАПУСК.bat всё равно открывает кабинет
- Telegram будет в демо-режиме, ответы — кнопкой «Симулировать»
